# 四季田园（cozy-farm）

> 一座随身携带的小农场：想快就快、想慢就慢，每次打开浏览器，都有作物在等你。

**治愈系田园经营 H5 小游戏** · 个人自用项目（不商业变现）· 桌面与移动端自适应

## 特色

- 🌱 **真实时间生长**：作物按游戏时钟生长，关掉网页农场也在安静生长（离线收益）
- ⏩ **时间流速可调**：在线随时切换 ⏸/1x/2x/5x/10x —— 沉浸时快进看四季流转，挂机时慢享等待
- 🍃 **无失败无压力**：作物永不枯萎、没有体力条、没有排行榜，所有目标都是邀请而非任务
- 📱 **双端适配**：桌面三栏布局 / 移动端全屏画布 + 底部标签栏，支持刘海屏安全区

## 技术栈

| 层 | 技术 |
|---|---|
| 系统层 | TypeScript（纯逻辑，零框架依赖） |
| 表现层 | Phaser 3（Canvas 渲染、瓦片地图） |
| 应用层 | Vue 3 + Pinia（面板 UI）+ Vite |
| 工程化 | pnpm workspace monorepo |

```
packages/
├── core/    纯 TS 系统层：GameState / TimeSystem / 数值表
├── game/    Phaser 表现层：场景与渲染（只读状态）
└── app/     Vue3 应用：UI 面板 / 挂载组装 / 存档
```

## 快速开始

```bash
pnpm install
pnpm dev        # http://localhost:5173 （--host 模式，手机同局域网可访问）
pnpm typecheck
pnpm build
```
