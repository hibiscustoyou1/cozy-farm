# 设计理念

> 《四季田园》的一切设计决策，都从这份文档出发。当实现细节与理念冲突时，以理念为准。

---

## 一句话概念

**一座随身携带的小农场：想快就快、想慢就慢，每次打开都有作物在等你。**

---

## 三原则

### 1. 无失败

玩家的任何操作、任何疏忽，都不应造成"损失"。

- 作物成熟后**永不枯萎**，晚几天来收也完好
- 不浇水只是**暂停生长**（土壤干了，作物原地等待），绝不枯死
- 换季时在地的上季作物**继续生长至成熟**，只是商店不再卖它的种子
- 动物断粮只是**停产**，不会死亡
- 没有"错过"：限时内容要么可补做，要么本来就不重要

> 对比：星露谷不浇水会枯萎、换季会清场——那是"经营压力"的设计。我们不要。

### 2. 无压力

不制造任何"必须上线"的焦虑。

- 没有体力条（想玩多久玩多久）
- 没有每日任务清单（不做完也不损失什么）
- 没有限时活动、没有倒计时促销
- 没有 PVP、没有排行榜、没有邻居比较
- 订单过期就过期了，**无惩罚**，新单自然到来

### 3. 有惊喜

关闭网页后，农场按 1x 安静生长（上限 8 小时）。

- 上线时弹出"欢迎回来"结算面板："你离开的 2 小时里，玉米成熟了、母鸡下了 2 个蛋"
- 每次打开都是一次**轻推门看看**的仪式感，而不是一次"补作业"

---

## 理论依据：治愈系游戏三要素

引用 Kowert 的治愈游戏理论（安全感 / 自主感 / 包容性），作为三原则的学术支撑：

| 要素 | 我们的落地 |
|---|---|
| **安全感**（可预期、熟悉、重复） | 季节与昼夜的固定节律；作物行为完全可预期；农场永远在那里等你 |
| **自主感**（自己决定做什么） | 无强制任务；速度流速自己选；种什么、摆什么、追哪个图鉴全是自己的事 |
| **包容性**（无失败惩罚） | 三原则之"无失败"；对疏忽宽容，对回归欢迎 |

## 时间哲学：双模式

本作最核心的机制决策：**在线可调速 + 离线固定 1x**。

### 为什么让玩家调速？

田园游戏存在两种幸福，传统产品只能二选一：

- **Hay Day 式**：真实时间慢生长 → 碎片时间的牵挂感，但沉浸时"没事可做"
- **星露谷式**：游戏内时间快进 → 沉浸时四季流转，但放下就没有延续感

速度选择器让玩家**在两种幸福之间自由切换**：

- 通勤地铁上 1x 种下西瓜，睡前收一波
- 周末下午 10x 快进，看云影飞驰、昼夜流转像延时摄影——**这本身就是治愈时刻**

### 两条不可破的边界

1. **离线永远 1x**：否则"10x 种菜 + 关网页"等于无限加速，时间系统失去意义
2. **速度有代价**：10x 下浇水湿度消耗也 10x——想快进就要更勤快地照顾农场。速度不是免费的外挂，而是另一种投入

### 时间刻度

- 1 游戏日 = 24 现实分钟（1x），含完整昼夜（日出 6:00 / 日落 18:00）
- 1 季 = 7 游戏日 ≈ 2.8 现实小时；1 年 = 4 季 ≈ 11.2 小时
- 10x 下 67 分钟跑完一年——四季轮转的观赏性拉满

## 目标感的自愿性

治愈 ≠ 没事可做。我们保留目标系统，但所有目标都是**邀请**而非**任务**：

| 系统 | 提供什么 | 自愿性体现 |
|---|---|---|
| 订单板 | 短期目标 + 1.4 倍收益 | 过期无惩罚，可手动刷新 |
| 图鉴收集 | 长线目标 + 称号 | 纯成就，图鉴页给获取提示防卡壳 |
| NPC 好感 | 情感连接 + 剧情解锁 | 不送礼也什么都不损失 |
| 装饰 | 表达欲出口 | 摆不摆、怎么摆全凭喜好 |

设计检验标准：**任何系统，玩家完全忽略它，游戏体验依然完整。**

---

## 反模式清单（我们明确不做的）

| 不做 | 原因 |
|---|---|
| 体力/疲劳系统 | 制造"今日额度"焦虑 |
| 作物枯萎/动物死亡 | 违反无失败原则 |
| 每日签到/任务清单 | 把"想来看看"变成"不得不来" |
| 限时活动/倒计时 | FOMO 是治愈的反面 |
| PVP/排行榜/好友比较 | 社交压力 |
| 抽卡/开箱 | 赌博机制与治愈基调冲突（且本项目不变现） |
| 强制新手引导长流程 | 三步提示可跳过 |
