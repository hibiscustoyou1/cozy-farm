# 美术风格

> 美术是治愈感的第一载体。本文档定义视觉基调与资源纪律，防止风格漂移。

---

## 总基调

**16×16 像素风 · 治愈系田园 · 低饱和暖色**

- 参考气质：星露谷的温暖 + 桃源深处有人家的柔和 + 动森的干净
- 一句话画面想象：*午后阳光下，一块被照料得很好的小农场*

## 像素规范

| 项 | 规范 |
|---|---|
| 基础图块 | 16×16 px |
| 角色/NPC | 16×24 或 16×32 px（Q 版二头身） |
| 渲染 | `pixelArt: true`（禁用平滑过滤）|
| 缩放 | 整数倍缩放（2x/3x/4x），避免半像素撕裂 |
| 相机 | 桌面看全局，移动端可拖拽 + 双指捏合缩放 |

## 四季色板（场景色调方向）

| 季节 | 主色调 | 氛围关键词 | 参考色 |
|---|---|---|---|
| 🌸 春 | 嫩绿 + 樱粉 | 苏醒、清新 | `#a8d5a2` `#f4c2d7` |
| ☀️ 夏 | 浓绿 + 天蓝 | 旺盛、明亮 | `#6bbf59` `#87ceeb` |
| 🍂 秋 | 橙黄 + 暖棕 | 丰饶、温暖 | `#e8b04b` `#c97b3d` |
| ❄️ 冬 | 蓝白 + 灰紫 | 安静、休憩 | `#dce8f2` `#9db2c9` |

- 全局原则：**低饱和、高明度**，避免高饱和撞色与纯黑
- 昼夜：日落/夜晚用整体色调滤镜（橙 → 深蓝），不改变物体本色

## 场景构成

```
[森林边缘]──┐
[小屋+院子]  ├── 农场主区域（5×4 起步，可扩至 10×8 耕地网格）
[池塘]──────┘          ↘ 农场外小径 → 森林/河滩/山脚（P3 探索区）
```

- 小屋是"家"的锚点，永远暖窗灯光（夜晚）
- 池塘留给钓鱼系统（P2）
- 留白很重要：地块之间保留草地/野花，不要满屏耕地

## 角色与动物

- 动物圆润化处理：鸡/牛用 2~3 头身，大眼睛
- NPC 各有辨识色（村长棕、老板娘红、渔夫蓝、木匠橙、旅人紫）
- 抚摸动物时的爱心粒子：粉白色，上浮消散

## UI 风格

| 项 | 规范 |
|---|---|
| 面板底色 | 米黄 `#fffdf5` / `#f4efe0`，木质圆角边框感 |
| 主色 | 叶绿 `#7fb069`（按钮/激活态）|
| 文字色 | 深绿 `#3d5a3d` |
| 字体 | **方舟像素字体 / Fusion Pixel**（开源中文像素字体，二选一后全局统一）|
| 触摸目标 | ≥ 44×44 px（移动端底线）|
| 图标 | 像素风图标，与场景素材同源 |

## 音频方向（附）

- BGM：lo-fi 钢琴/木吉他，按季节换 4 首，音量永远偏小
- 关键音效：收获（清脆"啵"）、浇水（水声）、金币（叮）、抚摸（咕噜）
- 昼夜切换：鸟鸣 → 虫鸣的淡入淡出

## 资源获取纪律

### 选型三原则

1. **主视觉优先采用同一作者的资源包**——风格统一优先于单个素材的精美。
2. **来源必须可追溯**——个人学习阶段可使用免费、AI 辅助或授权条件不同的素材，但必须登记来源、许可与 AI 披露；日后公开发布前再逐项复核和替换。
3. **跨来源素材先做适配**——统一像素尺寸、色板、描边与截图观感；禁止手绘风 UI 配像素场景等明显混搭。

### itch.io 候选清单（待验证授权后定稿）

| 资源包 | 内容 | 备注 |
|---|---|---|
| Cozy Farm Tileset（lungucristian1980） | 56 tiles + 作物 + 动物 + 四季 | 四季齐全，优先考察 |
| Pixel Farm RPG 16×16（JellyBeam） | 农舍、瓦片、农场动物 | 16×16 对口 |
| Little Dreamyland（Starmixu） | RPG 农场 + 森林探索 | P3 探索区候选 |
| Autumn Farming Pack（SableBytes） | 手绘风 | 备选（若转手绘路线则整套换） |

### 禁忌

- ❌ 像素场景配非像素 UI 图标
- ❌ 高饱和"手游炫光"特效
- ❌ 写实照片素材
- ⚠️ 未登记来源、许可或 AI 披露的素材混入（个人学习阶段允许 AI 辅助素材，但必须可追溯）

## 落地检查单（每次加新素材时过一遍）

- [ ] 与现有场景放在一起截图对比，色调是否和谐
- [ ] 授权是否确认（CC0 / 免费商用）？
- [ ] 是否同一作者/同一风格系？
- [ ] 16×16 网格对齐，整数倍缩放显示正常
- [ ] 移动端小屏下是否可辨识（不过度依赖细节）
